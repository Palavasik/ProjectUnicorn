# Спецификация MVP: Project Unicorn Bot

Версия: 1.0  
Дата: 2025

## 1. Цель MVP

Помочь бегуну-любителю быстро найти подходящий маршрут для бега от своей точки: дистанция задаётся пользователем, в результатах — до 10 вариантов с указанием типа поверхности у каждого.

## 2. Сценарии использования

### 2.1 Основной сценарий: поиск маршрута

1. Пользователь нажимает «Найти маршрут» или отправляет `/find`
2. Бот запрашивает точку старта: геолокация (кнопка) или координаты текстом (широта, долгота)
3. Пользователь отправляет геолокацию или вводит координаты
4. Бот показывает три кнопки дистанции: короткая (3–5 км), ежедневная (10 км), длинная (18–20 км)
5. Пользователь выбирает одну из кнопок
6. Бот выводит до 10 вариантов маршрутов; у каждого указаны название, дистанция, **тип поверхности** (асфальт, парк, трейл, набережная), описание, ссылка на карту

### 2.2 Отмена поиска

В любой момент диалога пользователь может отправить `/cancel` — поиск прерывается, состояние сбрасывается.

### 2.3 Неизвестная команда

При любом текстовом сообщении, не являющемся командой и не ожидаемым в контексте диалога, бот отвечает: «Не понимаю эту команду. Используйте /help для списка доступных команд.»

## 3. Команды

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и ценностное предложение продукта |
| `/help` | Список доступных команд |
| `/find` | Начать поиск маршрута |
| `/cancel` | Отменить текущий поиск |

## 4. Форматы данных

### 4.1 Маршрут (Route)

| Поле | Тип | Описание |
|------|-----|----------|
| id | string | Уникальный идентификатор |
| city | string | Город |
| name | string | Название маршрута |
| distance_km | number | Длина в км |
| surface_type | string | asphalt / park / trail / embankment |
| description | string | Краткое описание |
| features | array of string | Особенности (освещение, людность и т.д.) |
| map_link | string (optional) | URL карты (OpenStreetMap и т.п.) |

### 4.2 Файл данных

`data/routes.json` — массив объектов Route. Кодировка: UTF-8.

### 4.3 Логика поиска

**При наличии OPENROUTESERVICE_API_KEY:**
- Построение круговых маршрутов от точки старта (lon, lat) через ORS Directions (foot-walking) по 10 направлениям
- Тип поверхности для каждого маршрута определяется по данным ORS (extras.surface), отображается в выдаче
- Возвращается до 10 вариантов

## 5. Ограничения MVP

- **Запуск:** локально — polling; на Railway — webhook (HTTPS)
- **Источники данных:** OpenRouteService (при API-ключе) или `data/routes.json` (fallback)
- **Состояние:** хранится в памяти (`context.user_data`), сбрасывается при перезапуске бота
- **Точка старта:** геолокация или координаты (широта, долгота)
- **Валидация дистанции:** 1–50 км

## 6. Обработка ошибок

| Ситуация | Поведение |
|----------|-----------|
| Нечисловая дистанция | Повторный запрос с подсказкой |
| Дистанция вне 1–50 км | Повторный запрос |
| Маршруты не найдены | Сообщение «Маршруты не найдены. Попробуйте изменить параметры.» + предложение /find |
| Таймаут ORS | «Сервис маршрутизации не ответил вовремя. Попробуйте позже.» |
| Лимит ORS (429) | «Превышен лимит запросов. Попробуйте через несколько минут.» |
| Файл routes.json отсутствует | Пустой список (при fallback), логирование предупреждения |
