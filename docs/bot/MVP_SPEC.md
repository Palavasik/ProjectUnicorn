# Спецификация MVP: Project Unicorn Bot

Версия: 1.0  
Дата: 2025

## 1. Цель MVP

Помочь бегуну-любителю быстро найти подходящий маршрут для бега от своей точки: дистанция задаётся кнопками, маршруты предлагаются по ответу LLM (OpenRouter), по выбору пользователя формируется ссылка на построение маршрута в Яндекс.Картах.

## 2. Сценарии использования

### 2.1 Основной сценарий: поиск маршрута

1. Пользователь нажимает «Найти маршрут» или отправляет `/find`
2. Бот запрашивает точку старта: геолокация (кнопка), координаты текстом (широта, долгота) или адрес текстом (геокодирование через Nominatim или Яндекс при заданном ключе)
3. Пользователь отправляет геолокацию, вводит координаты или адрес
4. Бот показывает три кнопки дистанции: короткая (3–5 км), ежедневная (10 км), длинная (18–20 км)
5. Пользователь выбирает одну из кнопок
6. Бот вызывает OpenRouter с промптом из проекта и выводит список маршрутов (название, описание); под каждым — кнопка «Построить маршрут в Яндекс.Картах»
7. Пользователь нажимает кнопку выбора маршрута; бот отправляет ссылку на Яндекс.Карты с координатами выбранного маршрута

### 2.2 Отмена поиска

В любой момент диалога пользователь может отправить `/cancel` — поиск прерывается, состояние сбрасывается.

### 2.3 Неизвестная команда

При любом текстовом сообщении, не являющемся командой и не ожидаемым в контексте диалога, бот отвечает: «Не понимаю эту команду. Используйте /help для списка доступных команд.»

## 3. Команды


| Команда   | Описание                                      |
| --------- | --------------------------------------------- |
| `/start`  | Приветствие и ценностное предложение продукта |
| `/help`   | Список доступных команд                       |
| `/find`   | Начать поиск маршрута                         |
| `/cancel` | Отменить текущий поиск                        |


## 4. Форматы данных

### 4.1 Маршрут (Route)


| Поле         | Тип               | Описание                                 |
| ------------ | ----------------- | ---------------------------------------- |
| id           | string            | Уникальный идентификатор                 |
| city         | string            | Город                                    |
| name         | string            | Название маршрута                        |
| distance_km  | number            | Длина в км                               |
| surface_type | string            | asphalt / park / trail / embankment      |
| description  | string            | Краткое описание                         |
| features     | array of string   | Особенности (освещение, людность и т.д.) |
| map_link     | string (optional) | URL карты (OpenStreetMap и т.п.)         |


### 4.2 Файл данных

`data/routes.json` — массив объектов Route. Кодировка: UTF-8.

### 4.3 Логика поиска

**При наличии OPENROUTER_API_KEY:**

- Промпт загружается из файла (`config/prompts/route_search.txt` или ROUTE_PROMPT_PATH); подставляются стартовая точка (lat, lon) и дистанция (км)
- Вызов OpenRouter (Chat Completions); ответ — JSON с массивом маршрутов (name, description, coordinates)
- По нажатию кнопки выбора маршрута формируется ссылка на Яндекс.Карты (rtext=координаты)

## 5. Ограничения MVP

- **Запуск:** локально — polling; на Railway — webhook (HTTPS)
- **Источники данных:** OpenRouter (при OPENROUTER_API_KEY), промпт в `config/prompts/route_search.txt`; карты — ссылки Яндекс.Карты
- **Состояние:** хранится в памяти (`context.user_data`), сбрасывается при перезапуске бота
- **Точка старта:** геолокация, координаты (широта, долгота) или адрес текстом (переменные `GEOCODER_USER_AGENT`, опционально `YANDEX_GEOCODER_API_KEY`)
- **Валидация дистанции:** 1–50 км

## 6. Обработка ошибок


| Ситуация                          | Поведение                                                                               |
| --------------------------------- | --------------------------------------------------------------------------------------- |
| Нечисловая дистанция              | Повторный запрос с подсказкой                                                           |
| Дистанция вне 1–50 км             | Повторный запрос                                                                        |
| Маршруты не найдены / ошибка LLM  | Сообщение об ошибке + предложение «Найти маршрут» заново                                |
| Нет OPENROUTER_API_KEY            | «Поиск через LLM доступен только при настройке OpenRouter. Укажите OPENROUTER_API_KEY.» |
| Адрес не распознан геокодером     | Сообщение «Адрес не найден» + повторный запрос точки                                    |
| Геокодер недоступен (сеть / HTTP) | Сообщение о недоступности сервиса + повторный запрос точки                              |
| Файл промпта отсутствует          | Ошибка при старте поиска, логирование                                                   |
