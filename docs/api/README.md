# API Документация

## Telegram Bot API

### Команды бота

#### `/start`
Приветствие и ценностное предложение продукта.

**Ответ**: Текст с описанием возможностей и предложением использовать `/find`.

#### `/help`
Список доступных команд.

**Ответ**: Текст со списком команд: /start, /find, /cancel, /help.

#### `/find`
Начало сценария поиска маршрута.

**Ответ**: Запрос точки старта (геолокация, координаты текстом или адрес с геокодированием), затем три кнопки выбора дистанции. После выбора — вызов OpenRouter по промпту из проекта; вывод списка маршрутов (название, описание, гиперссылка «Открыть в Яндекс.Картах» в том же сообщении), затем отдельное сообщение с опросом «Как вам подбор маршрутов?».

**Кнопки дистанции (inline):** `distance:short` (4 км), `distance:daily` (10 км), `distance:long` (19 км).

**Опрос после подборки (inline):** `feedback:5`, `feedback:3`, `feedback:1`, `feedback:skip` — оценка или пропуск; в БД сохраняется с фиксированным именем маршрута «Подбор маршрутов».

#### `/cancel`
Отмена текущего поиска (в контексте ConversationHandler).

**Ответ**: Подтверждение отмены.

### Формат ответа со списком маршрутов

Текст в HTML: для каждого маршрута — название (bold), краткое описание, ссылка на Яндекс.Карты (построение маршрута по точкам, параметр rtext) в виде гиперссылки в тексте.

### Промпт и ответ LLM

- Промпт загружается из файла (по умолчанию `config/prompts/route_search.txt`), в нём подставляются `{{lat}}`, `{{lon}}`, `{{distance_km}}`.
- Ожидаемый формат ответа LLM — JSON: `{"routes": [{"name": "...", "description": "...", "coordinates": [[lat, lon], ...]}, ...]}`. Координаты в порядке [широта, долгота].

## Запуск

Бот работает в режиме **polling** (локально). Webhook не используется в MVP.
