# API Документация

## Telegram Bot API

### Команды бота

#### `/start`
Приветствие и ценностное предложение продукта.

**Ответ**: Текст с описанием возможностей и предложением использовать `/find`.

#### `/help`
Список доступных команд.

**Ответ**: Текст со списком команд: /start, /find, /cancel, /help.

#### `/find`
Начало сценария поиска маршрута.

**Ответ**: Запрос точки старта (геолокация, координаты текстом или адрес с геокодированием), затем три кнопки выбора дистанции. После выбора — вызов OpenRouter по промпту из проекта; вывод списка маршрутов (название, описание) и под каждым inline-кнопка «Построить маршрут N в Яндекс.Картах».

**Кнопки дистанции (inline):** `distance:short` (4 км), `distance:daily` (10 км), `distance:long` (19 км).

**Выбор маршрута (inline):** `route_select:0`, `route_select:1`, … — по нажатию бот отправляет ссылку на Яндекс.Карты с координатами выбранного маршрута (параметр rtext).

#### `/cancel`
Отмена текущего поиска (в контексте ConversationHandler).

**Ответ**: Подтверждение отмены.

### Формат ответа со списком маршрутов

Текст в HTML: для каждого маршрута — название (bold), краткое описание. Под списком — кнопки «Построить маршрут N в Яндекс.Картах»; по нажатию — сообщение со ссылкой на Яндекс.Карты (построение маршрута по точкам).

### Промпт и ответ LLM

- Промпт загружается из файла (по умолчанию `config/prompts/route_search.txt`), в нём подставляются `{{lat}}`, `{{lon}}`, `{{distance_km}}`.
- Ожидаемый формат ответа LLM — JSON: `{"routes": [{"name": "...", "description": "...", "coordinates": [[lat, lon], ...]}, ...]}`. Координаты в порядке [широта, долгота].

## Запуск

Бот работает в режиме **polling** (локально). Webhook не используется в MVP.
