# API Документация

## Telegram Bot API

### Команды бота

#### `/start`
Приветствие и ценностное предложение продукта.

**Ответ**: Текст с описанием возможностей и предложением использовать `/find`.

#### `/help`
Список доступных команд.

**Ответ**: Текст со списком команд: /start, /find, /cancel, /help.

#### `/find`
Начало сценария поиска маршрута.

**Ответ**: Запрос точки старта (геолокация или координаты), затем три кнопки выбора дистанции. После выбора — до 10 вариантов маршрутов с типом поверхности у каждого.

**Кнопки дистанции (inline):**

| Подпись              | callback_data   | Значение в км |
|----------------------|-----------------|---------------|
| Короткая (3–5 км)    | `distance:short`| 4             |
| Ежедневная (10 км)   | `distance:daily`| 10            |
| Длинная (18–20 км)   | `distance:long` | 19            |

#### `/cancel`
Отмена текущего поиска (в контексте ConversationHandler).

**Ответ**: Подтверждение отмены.

### Формат ответа со списком маршрутов

Текст в HTML:
- Название маршрута (bold)
- Дистанция и тип поверхности
- Описание
- Особенности
- Ссылка на карту (если есть)

### Внешние API

**OpenRouteService** (при наличии `OPENROUTESERVICE_API_KEY`):
- `POST /v2/directions/foot-walking/geojson` — построение маршрута от точки старта с `extra_info: ["surface"]`; тип поверхности определяется по данным ORS для каждого маршрута.

## Запуск

Бот работает в режиме **polling** (локально). Webhook не используется в MVP.
