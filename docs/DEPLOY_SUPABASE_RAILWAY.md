# Развёртка: Supabase + Railway

Пошаговая инструкция по настройке хранения пользователей и обратной связи в Supabase и деплою бота на Railway.

## Обзор

- **Сценарий 1**: при первом контакте (например `/start`) данные пользователя сохраняются в таблицу `users`.
- **Сценарий 2**: после выбора маршрута оценка сохраняется в таблицу `feedback`.

**Два варианта подключения к БД:**

1. **ORM (рекомендуется)** — задайте **`DATABASE_URL`** (строка подключения PostgreSQL из Supabase → Settings → Database). При старте приложения миграции выполняются автоматически, таблицы `users` и `feedback` создаются без ручного запуска SQL.
2. **Supabase REST** — задайте `SUPABASE_URL` и `SUPABASE_SERVICE_KEY`. Тогда таблицы нужно один раз создать вручную (SQL Editor и `scripts/supabase_schema.sql`).

---

## Шаг 1: Supabase

### 1.1 Создание проекта

1. Зайдите на [supabase.com](https://supabase.com) и войдите (или зарегистрируйтесь).
2. Создайте новый проект: **New Project**.
3. Укажите имя, пароль БД, регион. Дождитесь создания проекта.

### 1.2 Таблицы: автоматически (ORM) или вручную (REST)

- **Если будете задавать `DATABASE_URL`** (вариант с ORM): таблицы создавать вручную не нужно. При первом запуске бота выполнятся миграции Alembic и создадутся `users` и `feedback`.
- **Если используете только `SUPABASE_URL` + `SUPABASE_SERVICE_KEY`** (REST): откройте **SQL Editor** → **New query** → вставьте содержимое **`scripts/supabase_schema.sql`** → **Run**.

### 1.3 Получение данных для подключения

1. **Settings** → **API**: скопируйте **Project URL** (`SUPABASE_URL`) и ключ **service_role** (`SUPABASE_SERVICE_KEY`).
2. **Settings** → **Database**: в разделе **Connection string** скопируйте **URI** (для режима Session pool или Direct). Это значение для **`DATABASE_URL`** (подставьте пароль БД вместо `[YOUR-PASSWORD]`).

## Шаг 2: Railway

### 2.1 Переменные окружения

1. Откройте проект и сервис бота в [Railway](https://railway.app).
2. Перейдите в **Variables** (или **Settings** → Variables).
3. Добавьте переменные:

| Переменная | Значение | Описание |
|------------|----------|----------|
| `BOT_TOKEN` | Токен от @BotFather | Обязательно |
| `OPENAI_API_KEY` | Ключ OpenAI | Обязательно |
| `WEBHOOK_URL` | URL сервиса (например `https://your-app.up.railway.app`) | Обязательно для webhook |
| `DATABASE_URL` | Connection string из Supabase → Database (URI с паролем) | **Рекомендуется**: миграции при старте, не нужно вручную запускать SQL |
| `SUPABASE_URL` | Project URL из Supabase | Нужен, если **не** задаёте `DATABASE_URL` (режим REST) |
| `SUPABASE_SERVICE_KEY` | Ключ **service_role** из Supabase | Нужен, если **не** задаёте `DATABASE_URL` (режим REST) |

4. Сохраните переменные. Railway автоматически выполнит редеплой.

### 2.2 Проверка деплоя

Убедитесь, что сервис успешно запустился (логи без ошибок). При заданном `DATABASE_URL` в логах должно быть сообщение о применении миграций. Если заданы только `SUPABASE_URL` и `SUPABASE_SERVICE_KEY`, пользователи и отзывы сохраняются через REST API.

## Шаг 3: Проверка работы

### Пользователи (сценарий 1)

1. Отправьте боту команду `/start` (или нажмите «Главная», затем снова откройте бота и нажмите «Найти маршрут» — первый контакт может быть и там).
2. В Supabase откройте **Table Editor** → таблица **users**.
3. Должна появиться новая строка с вашим `telegram_user_id`, именем и датами `first_seen_at` / `last_seen_at`.

### Обратная связь (сценарий 2)

1. Пройдите сценарий поиска: «Найти маршрут» → укажите точку старта (геолокация или координаты) → выберите дистанцию.
2. После появления списка маршрутов нажмите «Построить маршрут N в Яндекс.Картах».
3. В ответ бот пришлёт ссылку и сообщение «Как вам маршрут?» с кнопками (Отлично / Норм / Не зашло / Пропустить).
4. Нажмите одну из оценок (например «Отлично»).
5. В Supabase в таблице **feedback** должна появиться запись с `telegram_user_id`, `route_name`, `rating`, `distance_km`, `created_at`.

## Локальная разработка

- **С ORM (миграции при старте):** задайте в `.env` только **`DATABASE_URL`** (Connection string из Supabase → Database). Запуск `python src/main.py` применит миграции и создаст таблицы.
- **Без ORM:** задайте `SUPABASE_URL` и `SUPABASE_SERVICE_KEY` и один раз выполните `scripts/supabase_schema.sql` в SQL Editor.
